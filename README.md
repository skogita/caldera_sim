# caldera_sim
Two-dimensional coupled simulator of caldera-forming eruptions (DEM roof, volatile-bearing chamber, ring-fault conduit) with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines X / カルデラ破局噴火の 2 次元連成シミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 X』の設計書とコード
